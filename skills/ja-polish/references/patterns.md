# 書き直しパターン集（before → after）

SKILL.md の手順 2 に対応する。上から順に適用する。出典は本多勝一『日本語の作文技術』、唐木元『新しい文章力の教室』、木下是雄『理科系の作文技術』、JTF 日本語標準スタイルガイド、textlint-ja のルール群、コミュニティの AI 臭チェックリスト（coji/natural-japanese、humanizer-ja、stop-ai-slop-jp）。

## 1. 削る

| before | after | 理由 |
|---|---|---|
| はい、もちろんです。このファイルを修正できます。 | このファイルを修正します。 | 冒頭の応答定型は情報を持たない |
| 以下の通りです。 | （削除） | 予告は本題を遅らせる |
| 本記事では〜について解説します。 | （削除して本題から始める） | 同上 |
| いかがでしょうか。／ご確認いただければ幸いです。 | （削除） | 締めの定型。必要なら具体的な依頼に置き換える（「明日までに返信をください」） |
| 〜にご注意ください。／〜をお勧めします。 | （削除、または条件を本文に組み込む） | 注意喚起の定型 |
| ## まとめ | （削除） | 本文で言い切れば要らない |

## 3. 語順と読点（本多勝一）

原則は 4 つ。節を句より先に。長い修飾語ほど先に。大状況を先に。読点は「長い修飾語の境界」と「語順が逆のとき」にだけ打つ。

| before | after |
|---|---|
| この設定はキャッシュが有効な場合に限りリクエストを高速化する。 | キャッシュが有効な場合に限り、この設定はリクエストを高速化する。 |
| 白い横線の引かれた厚手の紙 | 横線の引かれた厚手の白い紙 |
| この関数は引数は空のとき例外を投げる。 | この関数は、引数が空のとき例外を投げる。 |
| 設定を変更しましたが、反映には再起動が必要です。 | 設定を変更しました。反映には再起動が必要です。 |
| まず、設定を開きます。そして、値を変更します。 | まず設定を開き、値を変更します。 |
| API のレスポンスのバリデーションの処理 | API レスポンスを検証する処理 |
| 弊社の新製品の開発の担当者 | 新製品を開発する弊社の担当者 |
| 全く問題がないわけではない。 | 問題が残る。 |

## 4. 語彙

| before | after | 備考 |
|---|---|---|
| バリデーションを行う／実施する | 検証する | サ変名詞＋「を行う」は動詞に |
| 効率的な処理を実現する | 処理を速くする | 「実現」「向上」「図る」は具体動詞に |
| 可読性の向上を図る | 読みやすくする | 「〜性」の名詞化をほどく |
| 自動化を実施した | 自動化した | |
| 〜という点で／〜において | 〜は／〜で | |
| ソリューション／インサイト／アプローチ／ロバスト | 解決策／気づき／やり方／頑健 | 実装、デプロイ、リファクタ、マージは定着語なので残す |
| あなたのプロジェクトでは、私たちは〜 | このプロジェクトでは〜 | 英語直訳の主語は削る |
| ご確認いただけますでしょうか | ご確認ください／ご確認いただけますか | 二重敬語 |
| 〜させていただきます | 〜します | 許可を得る場面以外では過剰 |
| 出来る／事／為／更に／既に／全て／及び／又は／但し／従って／下さい／頂く | できる／こと／ため／さらに／すでに／すべて／および／または／ただし／したがって／ください／いただく | ひらく漢字。`check.sh --fix` が自動置換する |

## 5. リズム

| before | after |
|---|---|
| 設定を開きます。値を変更します。保存します。 | 設定を開いて値を変更し、保存します。 |
| 高速化を実現。保守性の向上。コストの削減。 | 速くなり、保守しやすくなり、コストも下がる。 |
| （全文が 45〜55 字で揃っている） | 10 字の短文を挟む。60 字を超える文を 1 つ残す。 |

文末の判定は最後の 2〜3 文字で見る。「ます」「です」「た」「る」「ない」が同じ形で 3 回続いたら 1 つを変える。変え方は、体言止め、疑問形、倒置、句読点で 2 文を 1 文にする、のどれか。

## 6. reader の指摘の扱い

| reader の指摘 | 対応 |
|---|---|
| 「この設定」が何を指すか不明 | 直前の文脈にあるなら名詞を明示する。ないなら不明点として返す |
| 「高速化」の比較対象が不明 | 原文に数値があれば添える。なければ不明点として返す |
| 「A または B の場合に C」が A(B C) か (A B) C か曖昧 | 読点か語順で一意にする |
| 専門用語が説明なしに登場 | 読者が想定読者なら残す。一般向けなら一言添える。判断できなければ不明点 |
